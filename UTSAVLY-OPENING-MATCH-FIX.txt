UTSAVLY opening consistency fix — 22 October 2026

Changes:
1. Fixed downloaded HTML asset indexing. The previous export read the opening asset list from the wrong Promise result whenever the selected card had image artwork, leaving the exported image map empty. Export now reads the asset list from its correct result slot.
2. Added a validation step so download fails with a visible error rather than silently exporting if any opening image (o_*.webp / ot_*.webp) could not be embedded.

4. The share path uses the existing studio/player bridge, which reconstructs the selected card artwork and normalizes the selected opening ID.
